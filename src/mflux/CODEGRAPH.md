## Summary

mflux is a comprehensive MLX-based image and video generation framework for Apple Silicon, implementing multiple diffusion model architectures (FLUX, FLUX2, QwenImage, ZImage, FIBO, SeedVR2, etc.) with support for text-to-image, image-to-image, inpainting, controlnet, LoRA fine-tuning, depth estimation, and various conditioning modalities. The project handles the full pipeline from weight loading/quantization through tokenization, transformer inference, VAE encode/decode, and output saving, with tooling for training adapters, callback management, CLI parsing, and model weight management.
